\# NLTK Chatbot 🤖



A basic terminal-based chatbot built with Python, NLTK, NumPy and Scikit-learn.



\## Features



\- Text preprocessing

\- Tokenization

\- Lemmatization

\- TF-IDF vectorization

\- Cosine similarity

\- Basic conversation handling

\- Unknown-query handling



\## Technologies Used



\- Python

\- NLTK

\- NumPy

\- Scikit-learn



\## How It Works



The chatbot converts the user's question and the chatbot's knowledge base into TF-IDF vectors.



It then uses cosine similarity to find the sentence that is most similar to the user's question.



If the similarity score is too low, the chatbot responds that it does not understand the question.
